Industrial Asset Behavioral Monitoring
======================================

A documentation site for the public repository accompanying a framework for
longitudinal behavioral monitoring, incident-family interpretation, and
reliability-informed analysis of weakly instrumented industrial assets.

Main components
---------------

- **Model_A**: operational-state inference from analog and digital signals
- **Model_B**: behavioral sequence extraction, nominal comparison, and longitudinal metrics
- **Model_C**: semantic and reliability-informed interpretation
- **Model_D**: incident episodes, registry alignment, and family occurrence summaries
- **Batch utilities**: month-wise orchestration for reproducible large-scale runs
